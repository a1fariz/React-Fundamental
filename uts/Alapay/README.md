# Alapay — Mini Project UTS React Fundamental 2026

Alapay adalah aplikasi katalog produk kopi, minuman, dan bakery berbasis React + Vite + Tailwind CSS. Data produk dibuat lokal tanpa database/API, sesuai ketentuan soal UTS.

## Checklist requirement

1. Dashboard statistik: total produk, produk tersedia, stok habis, wishlist, dan kategori.
2. Daftar produk: 16 produk dengan nama, gambar, kategori, harga, rating, stok, status, dan deskripsi.
3. Reusable component: navbar, hero, dashboard, filter, card produk, modal detail, floating action, dan footer dipisah.
4. Pencarian produk berdasarkan nama/kategori.
5. Filter kategori, status, wishlist, dan sorting.
6. Status produk: `Produk Baru`, `Best Seller`, `Diskon`, `Stok Habis`, `Stok Terbatas`, `Ready Stock`.
7. Wishlist interaktif dengan counter.
8. Detail produk melalui modal.
9. Event handling: tab view, search/filter, wishlist, update stok, dan tambah pesanan.
10. Layout responsif menggunakan utility Tailwind CSS.

## Teknologi

- React 19
- Vite 8
- Tailwind CSS v4
- Lucide React
- pnpm

## Cara menjalankan

```bash
cd c:/belajar/React_Fundamental/uts/Alapay
pnpm install
pnpm dev
```

Build production:

```bash
pnpm build
```
